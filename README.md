# 📊 Sales Performance Dashboard

## 🚀 Project Overview
This project is all about analyzing sales data using **SQL and Power BI**. The goal is to uncover insights on sales trends, customer behavior, and product performance by writing SQL queries and visualizing the results in Power BI.

## 📂 Datasets Used
We are working with three key datasets:
- **Customers.csv** – Contains customer details like names and locations.
- **Orders.csv** – Includes sales transactions and order details.
- **Books.csv** – Stores product information related to the books sold.

## 🛠️ Tools & Technologies
- **SQL** – Used for querying and analyzing the data.
- **Power BI** – Helps visualize key insights.
- **CSV/Excel** – Data sources for easy manipulation.

## 🔍 What We Analyzed
1. **Revenue Trends** – Tracking sales performance over time.
2. **Customer Segmentation** – Identifying high-value customers.
3. **Regional Sales Analysis** – Understanding which locations perform best.
4. **Product Performance** – Finding the best-selling and least-performing books.
5. **Sales Team Performance** – Measuring contributions from different sales representatives.

## 📑 What's Inside
- `Customers.csv` – Customer details.
- `Orders.csv` – Sales transaction records.

## 🎯 How to Use
1. **Import the datasets** into a SQL database like MySQL or PostgreSQL.
2. **Run the SQL queries** to analyze the data.
3. **Use Power BI** to create visualizations and dashboards.
4. **Customize and experiment** to find deeper insights.
